## DAS 的明确更正

作者本次确认的语义为：在有符号平方前 `t` 上拟合背景和筛选，在保留坐标上用原生 `t²` 聚合；Full 也聚合 `t²`。新 API 将拟合输入与聚合输入分开，专门的 `das-presquare` 入口只平方一次。双侧严格阈值选择不对保留分数再乘软权重；合法空选择记 0，拟合失败保持缺失。

源 V3 的 manifest 将有符号 `t` 标成 native，代码实际在拟合与聚合两处都用了 `t`。因此问题不限于报告措辞。历史 V3 的 DAS LDS、四法共同查询集合、E-DEL 选法与效用比较不能视作新定义的已验收结果。分数、子集响应、原生排序下的真实删除干预仍可复用；应重新拟合/聚合评价并重做选法。相关命令已写入报告，未在本次整理中执行。

## 可移植性

运行数据根由 `BALDS_DATA_ROOT` 或 `--data-root` 指定。模型位置、投影后端、设备与科学配置显式传入；代码不依赖 CFA 的绝对路径、SSH 别名或服务器。现有科学工件的相对路径和必要的历史 RNG 身份字符串保留，避免仅因目录改名改变随机数或工件身份。

基础安装只要求 NumPy、SciPy、PyYAML。训练、潜空间模型、投影、作图和测试依赖按 extra 安装。已经在独立虚拟环境内构建并安装 wheel，从项目目录外运行纯 CPU DAS 评价，确认无需 Torch。源项目的 Python 环境未被安装操作修改。

公开使用者仍须取得对应数据集和模型权重；这是实验输入，不能由空 `_Data/` 自动代替。导入 DAS 平台的原始 archive、ArtBench 数据/SD3.5 权重以及 CLIP 缓存条件见安装说明和迁移报告。原样复制的 Paper 中历史生产脚本保持原貌；整理后的便携作图入口位于 `Codes/Figure/`。
