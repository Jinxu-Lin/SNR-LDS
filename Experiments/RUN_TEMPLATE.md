# 新实验运行报告模板

每次实际运行在所属实验目录下建立记录；大产物放外部数据根，原始日志先放忽略的 `runs/`。
公开前提取与论文相关的记录并脱敏。尚未运行的命令应标为“复现配方”，不要填写完成状态。

- 实验目标和论文图表标签：
- 状态：配方 / 已运行 / 已核验 / 缺输入。
- 代码 Git commit、是否有未提交改动：
- 实际命令、配置文件及显式覆盖：
- 数据版本、训练行顺序、注入或子集身份：
- 模型 seed、检查点路径及 SHA-256：
- query IDs、split、生成/采样随机 seed：
- 硬件、Python / CUDA / 依赖版本：
- 开始/结束时间、退出状态、原始日志：
- 产物的相对路径、shape、SHA-256：
- 关键指标和核验方式：
- 缺项、数值差异及不能复现的历史步骤：

同一配方的多个 seed 应在同一实验档案中逐行记录，不复制三份源码。
代码变更用 Git 版本追溯；只在确有必要保存不可恢复的历史实现时附加最小源文件及来源说明。
